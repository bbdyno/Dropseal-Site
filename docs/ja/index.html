Dropseal
プライバシーサポート日本語

汗で開く
手紙がある。

DropsealはiPhoneの中のタイムカプセルです。手紙を書いて写真を添え、日付ではなく運動の目標で封印します。歩いて、燃やして、鍛えて、目標に届くまで開きません。

使いかた

  1. 1

    書く

    未来の自分への手紙、決意、今日の写真。文章と写真を好きなだけ。

  2. 2

    封印する

    封印を解く目標を選びます。50,000歩、3,000kcal、運動300分。封印したあとの活動だけを数えます。

  3. 3

    動く

    進み具合はヘルスケアから読み取ります。iPhoneとApple Watchの記録は重複せずに合算されます。

  4. 4

    開く

    動くほどに蝋がやわらかく溶けていきます。目標に届くと封印が解け、アプリを閉じている間なら通知でお知らせします。

封印に使える目標

歩数1,000歩から数百万歩まで
アクティブエネルギー消費したキロカロリー
エクササイズAppleのエクササイズ時間（分）
ウォーキング + ランニング距離（キロメートル）

iPhoneの中だけに

アカウントもサーバーもクラウド同期もありません。手紙と写真は端末にだけ保存され、ヘルスケアのデータは読み取るだけで、書き込んだりどこかへ送ったりしません。プライバシーポリシー
