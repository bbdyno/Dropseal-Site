진행률이 0%에서 안 움직여요

봉인한 뒤 건강 앱에 기록된 활동만 셉니다. 설정 › 건강 › 데이터 접근 및 기기 › Dropseal에서 읽기 권한을 확인해 주세요. Apple은 읽기 허용 여부를 앱에 알려 주지 않아 앱이 직접 확인할 수 없어요.

진행률이 늦게 바뀌어요

iOS는 새 건강 데이터가 생겨도 대략 한 시간에 한 번 정도만 앱을 깨우고, 잠긴 동안에는 건강 데이터를 읽을 수 없어요. 앱을 열면 바로 다시 계산해요. 백그라운드 갱신을 쓰려면 '백그라운드 앱 새로 고침'이 켜져 있어야 해요.

건강 데이터를 지우면 다시 봉인되나요?

아니요. 한 번 풀린 봉인은 그대로이고 진행률도 줄어들지 않아요.
